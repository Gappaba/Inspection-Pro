Inspection Pro v111

Both inspection types now show one Inspector section. When Database &
Sync is configured, the app uses the signed-in account and the active
technician profile with the same email address. Add or update that
profile in Technicians / Inspectors to supply the inspector name and
Minnesota inspector number. An account display name is used when there
is no matching profile and the account has a name on file.

The app confirms the account at signing. A reinspection tied to an
account can only be signed by that original account. Older reports
use their recorded technician profile or inspector details for matching.
Local-only installations retain one Inspector section for local entry.

Setup and reinspection also save the entered customer email. This
version does not send reports automatically.
