Inspection Pro v109

Reinspection is available for failed Minnesota MIP and Federal reports.

1. Open the original in Completed History and choose Start Reinspection.
2. Review the mileage, odometer source, inspector, plates, and other
   displayed information for the same vehicle. Edit anything that changed.
3. Reinspect the listed failed components and record PASS or FAIL. Use the
   remeasurement buttons for tires or brakes and update other measurements
   where needed. Open All Inspection Sections to recheck affected items
   that previously passed. Complete any missing checklist items.
4. Review and sign the follow-up. The app saves a separate report with
   its own number and a reference to the original. The result is PASS
   only if every required result is recorded and no failures remain.

Keep the original failed report. Retain earlier results only for the
same vehicle and components whose condition and applicability are
unchanged. The Federal PDF identifies results carried from prior reports.
The Minnesota PDF includes the original report reference in its notes.

Deficiency photos can be skipped on both forms. The description remains
required, and automatic failures include their measurement details.
