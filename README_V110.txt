Inspection Pro v110

Only the original inspector's selected technician profile can sign and
complete a reinspection. Mileage and other editable details remain
available. The original inspector's name and number are carried onto
the new report.

New reports save the matching technician profile ID when one is selected.
For earlier reports without a profile ID, the selected profile must
match the original recorded inspector name and inspector number when
one is on file. Select the correct profile in Technicians / Inspectors,
then reopen the reinspection draft.

This uses the app's technician profile selection. Individual inspector
sign-in or credential verification requires separate authentication.
